About the Prediction Model

This project predicts onion prices in Himachal Pradesh agricultural markets using historical mandi prices together with weather, seasonal, and festival information.

Model used: Polynomial Regression with Ridge regularization.

Important prediction features: days to festival, day of year, rainfall, average temperature, market, season, and year.

The model was trained using historical onion price data from 2023 to 2025.

The original model predicts price in rupees per quintal. Since one quintal equals 100 kilograms, the displayed price has been converted to rupees per kilogram (₹/kg).
